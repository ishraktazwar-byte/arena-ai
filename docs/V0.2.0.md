# V0.2.0 — strategic foundation

## Scope
An optional cloud planner sits above the deterministic body. Strict schemas
permit only scan, short wait and validated one-step ground movement. No eval,
model-generated JavaScript, arbitrary tool names or extra argument fields.
These are foundation tools, not the handoff's full mining/farming/building catalog.

- Node fetch, fixed openrouter/free routing, 20-second request timeout, at most
  three attempts, bounded Retry-After/backoff, response-size bounds and sanitized
  errors. Each network attempt reserves budget before sending.
- Shared daily request counter uses an exclusive filesystem lock and atomic
  replacement. Corruption, lock contention and orphaned locks fail closed.
- Strategies never overlap, respect configured intervals, and discard results
  after death/respawn, reflex activity, dimension change, movement, health loss
  or excessive response age. Goals still pass through body arbitration.
- Disabled/unavailable cloud planning falls back to read-only scanning, not
  invented mining actions. Local reflexes continue independently.
- Last 30 goal outcomes are kept in process memory, with five supplied as context.
  This is NOT persistent structured memory; restart clears it.

## API-contract correction found during review
Mineflayer exposes oxygenLevel in 0..20 units, not protocol air-supply ticks.
The earlier emergency threshold incorrectly compared to 60. Corrected to <=4
and added a regression test proving full oxygen (20) does not halt the agent.
This illustrates why API/source review and eventual live tests are required
in addition to mocks.

## Validation
62 automated tests pass locally on Node 22.22.3 and Node 24.21.0; syntax checks
pass. Provider tests use mocked HTTP responses, NOT real OpenRouter calls.
Budget tests use temporary directories and exercise contention/corruption.
Tests cover strict validation, free routing, bounded retries, no retry on auth
failure, oversized responses, budget refusal, stale responses and survival
preemption of strategic waits. Previous runtime/survival/combat tests still pass.
V0.1.3's GitHub matrix completed successfully on both Windows/Ubuntu and Node
22/24. V0.2.0 CI status is recorded by its workflow run, not inferred from V0.1.3.
No live Minecraft or live cloud-provider validation is claimed.
