# V0.2.8 — bounded local navigation

## Scope

Adds opt-in navigate_local with strictly validated integer x,z destination cells.
The LLM chooses where to go; deterministic routing decides whether and how the
local body can approach safely. The target is an empty cell center at the current
feet Y level, not a resource block occupied by solid material. Historical resource
knowledge never supplies a trusted route or confirms current resource availability.

MC_NAVIGATION_ENABLED defaults false. An explicit MC_NAVIGATION_AREA and dimension
are required independently of mining, collection and workspace permissions. The
runtime catalog carries copied constraints, and the conservative fallback excludes
this mutation. Navigation permission does not authorize other tools or intentional
collection. Minecraft incidental automatic pickups can occur during movement,
even on failed/cancelled attempts. No rollback is claimed.

This area governs navigate_local only, not all body movement. Existing survival,
operator-step, move_step and collection movement retain their own rules. Emergency
survival is not restricted by the navigation area's boundary.

## Routing and execution

- Minecraft Java 1.21.1, grounded on an approximately integer-height floor, health
  and food at least 12, NORMAL local risk, safe footing and no active container,
  cursor item or populated crafting grid.
- Destination and route stay within six horizontal blocks of the attempt's fixed
  origin and inside the approved area's player-footprint bounds.
- Breadth-first search enqueues at most 169 same-floor cells. Cardinal cell links
  check full body footprint, headroom and known inert support. One synchronous
  search caches block reads; every new search and moving-step check uses fresh
  terrain. The existing conservative support policy excludes unstable surfaces.
- Align toward the current cell center if needed; then use short cardinal links.
  No jumps, sprinting, stairs, slabs, swimming, digging, block placement or unknown
  terrain traversal. Routes may detour around an obstacle within the same bounds.
- Replan between legs; during movement check risk, stable body/dimension/elevation,
  approved footprint and current step geometry every 50 ms. A new obstacle on the
  active step fails safely rather than switching direction with controls engaged.
- At most twelve movement legs, each at most 700 ms, with a fourteen-second motion
  deadline and fifteen-second arbiter timeout. No progress or insufficient route
  budget fails; it does not produce an unbounded movement loop.
- Reaching within 0.25 horizontal blocks of the destination reports local arrival.
  Results explicitly set serverPositionVerified and resourceAvailabilityVerified
  to false: the body's local position estimate is not an inbound server position
  acknowledgement or evidence that remembered resources remain available.

The arbiter handles preemption and control cleanup. A late aim or abandoned wait
cannot issue movement once a new owner has control. Prior movement and incidental
world effects cannot be undone. Existing failed-action cooldowns apply to this tool.

## Integration

NAVIGATION-RESULT events report bounded outcomes and sanitized NavigationError
codes. Memory schema 7 reads schemas 1–6 and stores navigation results as history,
not routes to replay. Resource sightings retain the v6-compatible format and all
existing scoping/recheck requirements. No pathfinder dependency, extra provider
request or paid API requirement is introduced.

## Automated checks

New tests use a fake clock/physics fixture with the real bounded mover. Coverage
includes straight routes, obstacle detours, current-cell arrival, unreachable and
occupied destinations, unknown terrain/support, headroom, narrow area boundaries,
footprint/radius checks, body/dimension/elevation changes, danger, busy inventory,
terrain changes between/during legs, frozen-body timeout, twelve-leg exhaustion,
late arrival deadlines, cancellation during movement and preemption during aim.
Registry tests cover independent permission and diagnostics; memory tests cover
schema-v6 migration and navigation-history restart. All older tests still run.

No live Minecraft connection or real provider call is claimed. Live testing stays
deferred. This is local known-flat-terrain navigation, not general exploration,
long-distance travel, complete gathering or civilization-level readiness.
